venture capture

Allow reading LinkedIn profiles

The extension asks for site access only when you need it, so installing it grants nothing. To read a profile it needs permission for www.linkedin.com.

  • It reads a profile page when you press Capture — nothing in the background.
  • It never posts, messages, connects or acts as you.
  • You can revoke this at any time from chrome://extensions.

This page exists because Chrome only accepts a permission request from a click inside the extension itself — a button on a website cannot grant it.
